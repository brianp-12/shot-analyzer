# shot_analyzer

A mobile app that analyzes a person's form when shooting a basketball using YOLO-11. 

To run this project yourself just run
`flutter run`

To setup this project 
`flutter build apk --release`


 Dependencies
 `ultralytics_yolo` ^0.6.14
 `image_picker` ^1.2.3
 `google_fonts` ^8.2.1
